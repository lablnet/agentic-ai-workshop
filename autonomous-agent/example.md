# AI Agents Seminar

An AI agent observes its environment and takes actions to achieve a goal.

## Event-driven processing

1. A new document arrives in a folder.
2. The agent reads the document.
3. Gemini formats its content as a web page.
4. The agent saves the HTML and waits for another document.

## Collaboration

| Agent | Responsibility |
| --- | --- |
| Coordinator | Delegate the next task |
| Researcher | Prepare factual notes |
| Writer | Write and revise the explanation |
| Reviewer | Check accuracy and clarity |
